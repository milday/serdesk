## Troubleshooting

If you see "Demo Mode" instead of "Full Browser Automation":
1. Run `python test_gui.py` to check what's missing
2. Install missing packages: `pip install selenium webdriver-manager requests python-dotenv`

If browser doesn't open:
1. Make sure Chrome or Firefox is installed
2. Try the other browser option
3. Check the browser path settings in the GUI

If New Incident navigation fails:
1. The app now tries the updated XPath first, then falls back to the old one
2. Check the logs for specific error messages
3. Run `python test_new_incident_xpath.py` to test navigation specifically
